# Fruktbyggaren Cloudflare Multiplayer v32

- Ett större 50 × 50 meter stort rum.
- 20 svenska fruktnamn med engelska svar.
- Varje korrekt bokstav sparas direkt i Durable Object-lagringen.
- Versionsnummer visas på startknappen och resultattavlan.
- Tomma namn- och rumsfält.
- Startskärmen visar befintliga rum, antal spelare och antal klara ord.
- Tomma rum kan raderas; aktiva rum skyddas.
- Unika spelarnamn per rum.
- 1 poäng per rätt bokstav och ytterligare 10 poäng per färdigt ord.

Ladda upp filerna till samma GitHub-repository. Cloudflare publicerar automatiskt efter commit.
